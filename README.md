## 📖 The Story

The year is 2026.

An abandoned computer suddenly awakens with a mysterious message:

> Find my memories before the signal fades.

You enter an abandoned building where an AI named **ECHO** is waiting.

Explore forgotten locations, discover hidden clues, and uncover the mystery behind ECHO's lost memories.

Your decisions and discoveries influence how the story ends.

## ✨ Features

- 👻 Interactive text-based mystery adventure
- 🏚️ Five interconnected locations
- 🔎 Hidden clues and exploration
- 🤖 AI-generated dialogue using Google FLAN-T5 Small
- 🗺️ Room navigation and map
- 📊 Progress tracking
- 🎭 Three possible endings
- 💻 Runs directly in Google Colab

## 🕹️ Commands

| Command | Description |
|---|---|
| `help` | Display available commands |
| `look` | Examine your surroundings |
| `explore` | Search for hidden clues |
| `go ROOM` | Travel to another location |
| `ask QUESTION` | Communicate with ECHO |
| `clues` | Review collected clues |
| `map` | View available locations |
| `status` | Check your progress |
| `unlock ECHO` | Attempt the final mystery |
| `exit` | Leave the game |
